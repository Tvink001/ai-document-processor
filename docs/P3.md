
## Проект 3: n8n + Claude API «Обработка документов из Telegram»

### 📊 Анализ рынка (Freelancehunt)

Идеальное совпадение — проект **«Автоматизация n8n»** (`1603624`, 16.02.2026) с дословной цитатой:

> *«Автоматизація обробки документів через Telegram бот на платформі n8n… аналізом за допомогою Claude API, порівнянням з еталонним переліком документів у Google Таблиці, автоматичним проставлянням чекбоксів та формуванням архіву документів… Формати файлів: PDF, DOCX. Бот має приймати множинне завантаження файлів (до 6 штук за один запит)».*

Аналогичные проекты:

- **«Telegram Bot для извлечения данных из photo/pdf/word и Excel»** (`1595348`)
- **«AI-Конвертер PDF-заявок»** (`1605108`) — явный бюджет **2000 UAH ≈ $48** за MVP-скрипт
- **«Парсинг PDF банковских выписок»** (`1617295`) — ставки от 750 грн/час

**Средний бюджет:** от $50 за MVP-скрипт до $1500 за полноценный workflow с Claude + Sheets + архив. Типичный интервал MVP **$300–700**.

**Что чаще всего просят:** Telegram-бот принимает 1–6 файлов (PDF/DOCX/JPG), n8n распаковывает → OCR (если скан) → **Claude API с кастомным промптом** → сопоставление с эталонной таблицей документов → проставление чекбоксов в Google Sheets → возврат ZIP-архива или Excel-отчёта в Telegram.

### 🎯 Цель проекта

Полностью автоматизировать проверку пакета документов (например, для бухгалтерии или HR): менеджер бросает PDF-файлы в Telegram-бот, получает структурированный отчёт и готовый архив.

### ⚙️ Технический стек

- **n8n self-hosted на Railway free tier** (Docker-шаблон, ~$3/мес кредита хватает)
- **Узлы:** Telegram Trigger, Extract From File (PDF/DOCX текст), Anthropic Claude node (есть нативный в n8n), Google Sheets, Google Drive (для архива), Compression node для ZIP
- Для **OCR сканов** — Tesseract в Code node (`node:tesseract.js`) либо через Claude 3.5 Sonnet vision (принимает картинки напрямую, проще)
- **Модель** — Claude 3.5 Haiku для скорости и $1/M токенов, Claude 3.5 Sonnet для vision

### 📄 Функциональные требования

Пользователь отправляет в Telegram-бот 1–6 файлов (можно подряд или одним альбомом). n8n собирает все файлы одной сессии (окно 5 сек через `Wait` + `Merge`), для каждого определяет тип (MIME), извлекает текст:

- для **PDF** — `pdf-parse`
- для **DOCX** — `mammoth`
- для **JPG/PNG** — отправка изображения напрямую в Claude Vision

Весь извлечённый текст + список эталонных документов (из Google Sheets лист `template`) уходит в Claude API с промптом:

> *«Определи тип документа (из списка), извлеки ключевые поля: дата, номер, сумма, контрагент. Верни строго JSON со схемой `{type, date, number, amount, contractor, confidence}`».*

Ответ парсится, результат записывается в Google Sheets (одна строка на файл, колонка `type` → тикбокс в шапке), все файлы сохраняются в папку Google Drive с именем `{дата}_{тип_документа}_{номер}.pdf`.

Из папки формируется ZIP (через Google Apps Script webhook) и возвращается пользователю в Telegram сообщением: ✅ `Обработано 6/6 документов. Отсутствуют: [список]. Архив: [ссылка]`.

### 🔌 Интеграции и API

- **Anthropic Claude API** — регистрация на console.anthropic.com, при входе дают $5 кредитов (хватает на ~2500 обработок Haiku или ~300 Sonnet)
- **Telegram Bot API** через BotFather
- **Google Sheets + Drive + Apps Script** — бесплатно
- **n8n self-hosted:** Railway template `n8n` (одна кнопка)
- Для **OCR сканов без Claude Vision** — бесплатный **OCR.space API** (25000 запросов/мес free) или локальный Tesseract в Code-node

### 🗂 Структура данных

**Лист `template` (эталон):** `id`, `document_type`, `required_fields` (JSON), `is_required` (bool)
**Лист `sessions`:** `session_id`, `user_id`, `username`, `started_at`, `files_count`, `status`
**Лист `documents`:** `session_id`, `file_id`, `file_name`, `detected_type`, `date`, `number`, `amount`, `contractor`, `confidence`, `drive_url`, `processed_at`
**Лист `_report` (pivot):** строки — `session_id`, колонки — типы документов, значения — ✅ / ❌

### 🚀 Этапы разработки

1. Стартовать с минимального воркфлоу: `Telegram Trigger → Download File → Extract From File → Set → Google Sheets Append` (без AI), отладить на 3 тестовых PDF
2. Добавить **Claude node** с промптом и парсингом JSON (через `JSON.parse` в Function-node с try/catch)
3. Обработка альбома (Wait 5s + Aggregate)
4. DOCX (`mammoth` library в Code node) и сканы (Claude Vision — просто передать base64 картинки)
5. Google Drive upload и именование файлов
6. Apps Script для ZIP и финальное уведомление
7. **Предфинал** — retry-логика для Claude (если API вернул не-JSON — один повтор с `temperature 0`)

### ✅ Критерии готовности

- 6 разношёрстных документов (2 PDF, 2 DOCX, 2 скана JPG) за одну сессию обрабатываются за **<60 секунд**
- Распознаются правильно в **≥90%** случаев
- Заполняют Google Sheets, сохраняются в Drive с человекочитаемыми именами, архив отдаётся в Telegram
- Отсутствующие обязательные документы отмечены красным
- Стоимость одной сессии **≤ $0.02** (Claude Haiku)
- В README есть демо-видео и примеры реальных документов (обезличенные)

### 💡 WOW-функции для портфолио

- **Умный retry с эскалацией моделей:** если Haiku вернул `confidence < 0.7` — автоматический повтор на Sonnet с полным контекстом (цена выше, но точность ~99%)
- **Обнаружение дублей:** перед записью сверяется хэш (MD5) файла со всеми ранее обработанными — мгновенный возврат результата без повторного вызова Claude
- **Генерация готового письма с замечаниями:** после проверки Claude пишет короткое письмо клиенту вида *«получили ваш пакет, не хватает: …, ждём до …»*, готовое к отправке через Gmail node одной кнопкой
